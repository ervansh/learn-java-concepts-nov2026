# Object-oriented programming
## Theory
Encapsulation protects object state behind methods. Inheritance reuses and specializes behavior. Polymorphism allows a supertype reference to invoke an implementation selected at runtime. Abstraction exposes essential behavior while hiding implementation detail. Composition models a has-a relationship.
## Concepts
- Classes, objects, fields, methods and constructors.
- Encapsulation, inheritance, abstraction and polymorphism.
- Overriding, overloading, `this`, `super` and composition.

## Pitfalls
- Deep inheritance hierarchies.
- Public mutable fields.
- Confusing compile-time overloading with runtime overriding.
